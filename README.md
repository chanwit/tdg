# TDG - Test-Driven Generation Plugin

A Claude Code plugin for test-driven generation workflows.

## About

TDG (Test-Driven Generation) enhances Claude Code with capabilities for test-driven development and generation workflows.

## Installation

```bash
# Add the TDG marketplace
claude plugin marketplace add chanwit/tdg

# Install the plugin
claude plugin install tdg
```

## Components

- **Commands**: Custom slash commands (coming soon)
- **Agents**: Specialized agents for TDG workflows (coming soon)
