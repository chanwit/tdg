description: Help create clean, atomic commits by analyzing changes and detecting mixed concerns
---

Use the Skill tool to invoke the "tdg:atomic" skill, which will help create clean, atomic commits.

The atomic skill will:
1. Analyze your current changes using git status and git diff
2. Detect any mixed concerns (multiple features, fixes, or refactorings)
3. Group files into logical atomic commits
4. Guide you through creating each commit with proper testing and validation
5. Ensure each commit is a complete unit of work that can be reverted independently

Invoke the skill now to begin the atomic commit workflow.
